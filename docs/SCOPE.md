# 범위와 근거

## 사용자와 합의한 첫 범위

기술 기반과 최소 플레이부터 진행한다. 원작 시점과 자료는 제공되지 않았다. 원작 콘텐츠·수치를 알아낸 것처럼 채우지 않는다.

## 공고에서 확인한 사실

Unity 6 클라이언트, C#/.NET 서버, TCP/TLS, Protobuf, PostgreSQL을 사용한다. 전투·AI·퀘스트·경제·소셜 콘텐츠와 테스트·디버깅·코드 리뷰가 직무에 포함된다. 공고의 동접 30만 명은 아르테일 운영 경험이며 본 프로젝트 목표 동접으로 해석하지 않는다.

## 이번 구현의 자체 설계

| 항목 | 자체 설계값 | 원작 확인 여부 |
|---|---|---|
| 논리 공간 | 반경 7의 2차원 원형 맵 | 미확정 |
| 표현 | 반경 12 구의 위쪽 표면에 좌표 투영 | 미확정 |
| 이동 | 요청당 최대 0.24, 최소 80ms 간격 | 미확정 |
| 공격 | 거리 1.5, 최소 400ms 간격 | 미확정 |
| 몬스터 | HP 3, 고정 위치, 3초 재생성 | 미확정 |
| 처치 보상 | 조각 1개 | 미확정 |
| 퀘스트 | 3회 처치, 골드 100, 캐릭터당 1회 | 미확정 |
| 네트워크 | 10Hz 요청/응답, 최대 16연결, 32KiB 프레임 | 자체 시험 설계 |

모든 위 값은 원작 수치라는 주장을 하지 않는다. 원작 클라이언트·자산 분석은 아직 수행하지 않았다.

## 원작 관찰 명세 양식

각 기능에 자료 출처, 대상 버전, 관찰 입력, 관찰 결과, 실패 조건, 추정한 내용, 검증 방법을 붙인다. 클라이언트의 관찰로 알 수 없는 서버 내부 구조는 독립 구현으로 기록한다.

## 첫 완료 기준

서로 다른 두 계정이 접속하고 서로를 볼 수 있다. 서버가 이동·공격을 검증한다. 처치와 보상은 재접속·서버 재시작 뒤 유지된다. 중복 보상과 잘못된 요청을 거부한다. Unity Windows 실행 파일과 검증 근거를 제공한다.

## 전체 서비스까지 남은 작업

- 원작 기준 버전과 전체 콘텐츠 목록 확정
- 데이터 기반 맵·NPC·몬스터·아이템·퀘스트 제작
- 전투·스킬·AI·성장·장비·경제
- 파티·채팅·친구·길드·거래
- 실제 콘텐츠 채움과 클라이언트 완성
- 운영 권한·감사 이력·백업 복원
- 부하·장애·악용 검증과 병목 개선
- 배포·모니터링·패치·외부 테스트
- 배포 자산의 사용 권한 및 출시 준비

각 단계의 완료를 실제 결과와 검증 로그로 판단한다. 현재 구현을 원작 완성이나 라이브 운영 가능 상태로 소개하지 않는다.
