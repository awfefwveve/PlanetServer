서비스 인수 준비 현황 — 2026-10-10

판정: 현재 프로젝트는 개발 중인 재현 시제품이다. 회사에서 바로 상용 서비스할 수 있는 완성품이 아니다.
원작의 내부 서버 구현, 전체 데이터, 원본 모델/애니메이션을 확보한 프로젝트가 아니다.
원작 영상에 근거한 관찰과 직접 작성/생성한 대체 구현을 구분해야 한다.

실제 구현된 범위
- 별도 C#/.NET 서버 프로세스. Unity는 TCP/TLS + Protobuf로 서버에 연결한다.
- 클라이언트가 PostgreSQL에 직접 접속하지 않는다. DB 접근은 서버 저장소 구현이 담당한다.
- 계정/비밀번호 PBKDF2, 중복 로그인 거부, 패킷 크기/빈도 제한.
- 서버 캐릭터 생성/목록/선택, 외형 저장, 이름 확인.
- 채널 자동 배정/정원/예약 및 채널 이동. 채널 목록 30개.
- 이동/거리/공격 쿨다운/포탈 판정, 지역 분리.
- 초원 슬라임 5개: ID별 HP/죽음/리스폰, 처치 조각/퀘스트 보상 저장.
- revision과 저장 성공 후 반영. FileStore와 PostgreSQL 저장소.
- 같은 채널·지역 채팅, UI 입력과 서버 송수신.
- 곡면 시각 변형, 평면 논리 좌표/높이, 2D 캐릭터와 3D 배경 조합.

원작과 다르거나 임시인 범위
- 현재 meadow/coast/forest/hill/garden은 직접 정의한 소규모 지역이다. 원작 전체 월드가 아니다.
- 몬스터 수치/배치/보상은 시제품 규칙이다. 원작 데이터라는 근거가 없다.
- 그래픽은 사용자 참조 이미지의 일부 샘플, 생성 이미지, 직접 만든 메시가 혼합돼 있다.
- 영상에 보이는 전체 기능/퀘스트/맵/직업/성장/장비/경제가 구현된 상태가 아니다.
- HUD의 일부 수치/아이콘/미니맵은 예시 표시다. 레벨/스킬 전체 기능 완료가 아니다.
- 나린 일부 외형의 방향별 움직임만 있고 모든 캐릭터/장비/공격 동작은 없다.
- 도착 연출은 카메라 궤도 근사다. 원작 비행선/궤적/맵 원본 구현이 아니다.

서버의 실제 운영 제한
- 기본 전체 연결 제한 128, 채널 정원 32. 1,000명/채널 실측 검증 없음.
- 채널 단위 잠금과 계정 단위 잠금. 저장 대기와 게임 처리가 결합된 부분이 있다.
- 지역별 독립 tick, 공간 AOI, 다중 서버로 지역 소유권을 이전하는 구조는 미완성.
- 현재 서버는 loopback 127.0.0.1에 바인딩한다. 공개 서비스 배포가 아니다.
- 재시작 시 영구 캐릭터 데이터 복원과 프로세스 장애 시 전체 실시간 상태 복구는 다르다.
- 자동 장애조치, 운영 관측/경보, 관리자 기능, 백업 복구 훈련, 배포/마이그레이션 검증은 미완성.
- 장시간 부하, 접속 폭주, 지연/패킷 분할, 저장 장애 등 상용 목표별 추가 측정이 필요하다.
- 개발용 인증서와 로컬 자동 계정 실행 방식은 상용 로그인 체계가 아니다.

이번 구조 수정
- Assets/Scenes/MeadowAuthoring.unity: 실행 전 열 수 있는 초원 편집 씬.
- Assets/Resources/Regions/meadow.prefab: 저장된 배경 오브젝트/머티리얼/메시.
- 실제 플레이의 meadow는 이 프리팹을 읽는다. 다른 지역은 아직 코드 생성 방식.
- UI는 아직 실행 시 생성 방식이다. UI 프리팹 전환 완료로 보고하지 않는다.
- 지형 높이/서버 충돌은 RegionTerrain/Regions 데이터 기준이다.
  배경 나무를 이동했다고 서버의 장애물 판정이 자동 갱신되지는 않는다.
  서비스용 편집 도구에는 서버용 지형/충돌 데이터 내보내기와 검증이 추가로 필요하다.
- EverPlanet 메뉴의 개발 서버 시작: 에디터 전용 로컬 계정/파일 저장.
  PostgreSQL 환경이나 기존 Play.cmd 데이터와 혼동하지 않도록 data-editor에 분리.
