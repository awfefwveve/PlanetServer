## Unity 실행 파일의 전체 흐름

실행 파일이 실제 TCP/TLS 서버에 접속해 자동 입력으로 이동·공격·퀘스트 수령을 수행했다. JSON 모드와 PostgreSQL 모드 모두 22초 시점에 처치 5회, 조각 5개, 골드 100, 보상 수령 상태 true를 확인했다. `gameplay-result.txt`에 PostgreSQL 모드 결과를 보관했다.

`preview.png`는 월드 카메라를 별도로 렌더링한 실제 장면이며, HUD는 포함하지 않는다. 임시 행성·캐릭터·슬라임·경계가 표시되는 것을 확인했다. 숨김 창의 화면 캡처가 지원되지 않아 카메라 직접 렌더링으로 검증했다. 로그인 화면의 수동 키보드 조작과 두 Unity 창 간 동시 조작은 별도 사용자 확인 대상이다. 두 클라이언트의 공동 접속은 네트워크 통합 테스트로 확인했다.

## PostgreSQL 검증 환경

Docker는 이미지 다운로드 DNS 오류로 사용할 수 없었다. EDB에서 제공하는 PostgreSQL 17.11 Windows 배포를 작업 폴더에 풀고, `127.0.0.1:55432`의 독립 테스트 DB에서 검증했다. 시스템 서비스로 등록하지 않았다. 검증 후 해당 테스트 DB 프로세스는 종료한다.

배포 출처: https://www.enterprisedb.com/download-postgresql-binaries
